# Landing de Dados · Eduardo Campregher

Jornada **prompt a prompt** até a landing. Sem instalar nada.

Prompts: `prompts/md/` e `prompts/pdf/` (pacote: `prompts/pdf/Prompts_Completo.pdf`).

## Ordem

1. `prompts/md/00_mestre.md` nas instruções do chat
2. `01_limpar.md` + `dados/*.csv` → `outputs/`
3. `02_json_landing.md` → `outputs/02_landing.json`
4. `03_contrato.md` → `outputs/03_contrato_produto.md`
5. `04_produto.md` → **`produto/index.html`**
6. `05_juiz.md` → `outputs/05_juiz.md`

Mapa, como funciona e como usar a tela: `prompts/md/`. Produto: `produto/index.html`.
