# CSOps Reuniões · Juliana Caballero

Jornada **prompt a prompt** até a Mesa CS. Sem instalar nada.

Prompts em `prompts/md/` (editar) e `prompts/pdf/` (colar no Gemini). Pacote unico: `prompts/pdf/Prompts_Completo.pdf`.

## Ordem

1. Cole `prompts/md/00_mestre.md` nas instruções do chat.
2. `01_limpar.md` + CSVs de `dados/` → `outputs/`
3. `02_fichas.md` → `outputs/02_fichas.json`
4. `03_contrato.md` → `outputs/03_contrato_produto.md`
5. `04_produto.md` → **`produto/index.html`** (abra no navegador)
6. `05_juiz.md` → `outputs/05_juiz.md`

Mapa: `prompts/md/MAPA_ARQUIVOS.md`. Como funciona: `prompts/md/COMO_FUNCIONA.md`.
Como usar a tela: `prompts/md/MAPA_FUNCIONALIDADE.md`.

Produto: `produto/index.html`.
