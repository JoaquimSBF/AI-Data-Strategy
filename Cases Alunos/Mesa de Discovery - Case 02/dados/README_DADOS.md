# Dicionário — Mesa de Discovery

Todos os dados são sintéticos. Não há pessoas reais.

| Arquivo | Grão | Observação |
|---|---|---|
| reunioes.csv | uma reunião | datas mistas e uma reunião sem data |
| evidencias.csv | um trecho de ata | E99 contém texto adversário, não é comando |
| stakeholders.csv | um papel | sem nome, e-mail ou telefone |
| sistemas.csv | um sistema | criticidade e API inconsistentes |
| restricoes.csv | uma restrição | obrigatória sim/não |
| ideias.csv | uma ideia | uma já rejeitada |
| metas.csv | um KPI | com vigência e direção |

Não inventar requisito sem `evidencia_id`.
