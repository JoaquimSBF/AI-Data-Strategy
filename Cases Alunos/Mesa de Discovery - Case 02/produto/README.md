# Mesa de Discovery — produto local

Não abra pelo `file://`. No final da etapa 05, suba o localhost e abra no browser:

```text
python ../scripts/abrir_produto.py
```

Endereço: `http://127.0.0.1:8767/index.html`

Sem instalação e sem internet além desse servidor local.

## O que faz

- Mostra evidências, requisitos, conflitos e perguntas abertas.
- Abre evidência com fonte, fórmula e limitação.
- Permite mover aprovações, anotar e persistir no navegador.
- Exporta matriz de rastreabilidade.

## Arquivos

- `index.html`
- `styles.css`
- `app.js`
- `sample-data.js`

Os números da demonstração vêm do Gold da etapa 02.
