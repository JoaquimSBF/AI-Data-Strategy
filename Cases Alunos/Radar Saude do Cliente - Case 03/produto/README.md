# Radar de Saúde do Cliente — produto local

Não abra pelo `file://`. No final da etapa 05, suba o localhost e abra no browser:

```text
python ../scripts/abrir_produto.py
```

Endereço: `http://127.0.0.1:8768/index.html`

Sem instalação e sem internet além desse servidor local.

## O que faz

- Mostra carteira, sinais e detalhe do cliente.
- Exibe churn mensal como `sem evidencia`.
- Permite mover ações, anotar e persistir no navegador.
- Recusa rótulo de probabilidade de churn.

## Arquivos

- `index.html`
- `styles.css`
- `app.js`
- `sample-data.js`

Os números da demonstração vêm do Gold da etapa 02.
